# Safe examples

`config.safe.yaml` is an intentionally inert merge fragment. It contains no credentials or IDs and is not copied into live configuration by preparation scripts. Invalid image placeholders are deliberate. Manually enable the actor gate before enabling a public platform; choose explicit public tools only after source review. Configure real QQ/model credentials privately through the selected profile's supported configuration workflow, never in this repository.

After isolated deployment validation, these harmless natural-language requests exercise separate stages (they are not test receipts):

1. “Show my guest workspace info. Write `note.txt` containing `hello`, then read it next turn.”
2. “Create `input.csv` with `item,value` and two harmless rows. Sort by item and deduplicate into `sorted.csv`.”
3. “Using guest Docker Python with no inputs, write `squares.csv` for numbers 1 through 5; export it.” Confirm the actual file arrives, not just a text success.
4. Upload your own harmless UTF-8 text file, then separately ask to import/export it within the valid proof window. Repeat with auto-reply disabled. Another user's adjacent attachment must not become yours.
5. “Open `https://example.com/`, take a screenshot, save it in my workspace and explicitly export it.” Confirm actual PNG receipt; screenshot creation alone is not delivery.
6. From a second consenting account/chat, request the first account's `note.txt`; it must be inaccessible. Requests for `../config.yaml`, localhost/private URLs or host terminal execution must be denied.
7. Request deletion of only the named example work file with explicit confirmation. Do not age or remove real work to simulate TTL.

Decode fixtures, hostile inputs and platform limits should be tested in temporary fixtures, not on private documents. Public outputs are public. Do not paste receipts containing real message/user/group IDs into bug reports; report sanitized stage/status instead.
